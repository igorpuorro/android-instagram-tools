# feed_autoplay settings -- used when feed_autoplay.exe is started without options (double-click).
# Put a "#" in front of an option to turn it off; "#" starts a comment. Started from a terminal
# with options (feed_autoplay.exe --play all --2x), this file is ignored.
# All options and what they do: feed_autoplay.exe --help, or README.txt.

# playback
--play all               # all = every video; followed = only accounts you follow
--2x                     # play at 2x speed (key x switches it during a run)
# --max-watch 300        # stop watching a video after this many seconds
# --brightness 30        # phone screen brightness at start (keys < > change it while running)
# --battery-stop 10      # stop when the phone's battery is this low and not charging (0 = only warn)

# actions on videos watched to the end: none, followed or all
--like all
# --comment followed       # public, under your name; needs a text or a script below
# --comment-text "🇧🇷🇧🇷"   # the comment (keep the quotes)
# --comment-script comment_greeting.bat   # or a script that prints a comment per video (README.txt)
--repost all             # reposts show on your profile; Instagram limits them
--share-link all         # copies each link into runs\shared-links.txt
--save all               # private Saved collection
